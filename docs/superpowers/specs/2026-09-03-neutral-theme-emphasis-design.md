# 中性主题低强调度设计

## 目标

将默认中性主题的选中背景和滚动条降低到 C 档极淡强度，同时让浅色和深色模式都保持可辨识。

## 范围

- 通过现有外观颜色生成器降低 `sidebarSelected` 的混色比例：浅色模式 10%，深色模式 20%。
- 通过全局 CSS token 统一应用内滚动条的静止态与悬停态：浅色使用前景色 8% / 16%，深色使用前景色 10% / 18%。
- 内置浏览器的网页在每次页面加载完成后插入同等强度的滚动条 CSS；因为网页运行在独立 `webview` 中，不能继承渲染器的全局 CSS。

## 不在范围内

- 不改变滚动条尺寸、布局或主题设置界面。
- 不增加设置项、数据迁移或兼容层。
- 不修改用户当前工作区中的非外观改动。

## 验证

- 颜色生成器测试会断言中性主题在两种模式下的选中背景颜色。
- 浏览器样式测试会断言浅色和深色网页都生成极淡静止态与更清晰的悬停态。
- 桌面端相关测试、类型检查和生产构建用于验证集成。
