# 浅色主题文字色调设计

## 目标

让默认浅色主题的主文字从接近纯黑的观感调整为柔和深灰，使内容区、工具栏、列表和弹窗的阅读感更接近 Codex 截图，同时保持中文小字号可读性。

## 设计

- 将浅色主题的主文字色从 `oklch(0.145 0 0)` 调整为 `oklch(0.30 0 0)`，约为 `#2D2D2D`。
- `foreground`、`card-foreground` 与 `popover-foreground` 使用同一主文字色，确保页面、卡片和弹窗的文字黑度一致。
- `ui-foreground` 与 `content-foreground` 已引用 `foreground`，会自动继承新的色调，无需在组件中增加硬编码颜色。

## 保持不变

- 次级文字、侧栏辅助文字、链接、强调色、危险色与焦点环。
- 深色主题中的文字 token。
- 字体、字号、字重、布局和用户外观设置存储。

## 验证

- 更新外观 token 的测试，断言浅色主题的主文字与卡片/弹窗文字使用新的深灰值。
- 运行桌面端相关测试、类型检查和生产构建。
