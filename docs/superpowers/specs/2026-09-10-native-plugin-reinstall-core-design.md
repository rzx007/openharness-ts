# Native Plugin 重新安装核心设计

> 状态：已确认设计。

日期：2026-09-10

## 1. 结论

本阶段不建设独立的插件更新、修复或回滚系统。用户在 Desktop 插件页重新导入同一插件 ID 的 Native ZIP，就是唯一的更新与修复入口。

现有安装器已经具备核心安全语义：先校验并生成不可变快照，成功后才原子更新 `installed.json`；同版本、同摘要的目标快照损坏时，会先隔离损坏目录，再从本次可信输入重建。因此本阶段只补齐重新安装时缺少的状态继承和权限复用，不重复实现安装器。

## 2. 用户流程

入口仍是 Desktop 插件页的“导入插件”，不增加“检查更新”“修复”或版本管理按钮。

```text
选择一个 Native ZIP
→ 安全解压并执行 Native 校验
→ 按插件 ID 查询现有用户安装记录
→ 判断本次权限是否已被之前的批准覆盖
→ 必要时显示一次完整权限确认
→ 调用现有 Native Installer
→ 新快照成功后切换安装记录
→ 返回成功、失败或结果暂无法确认
```

成功反馈统一使用“已安装或更新，将在下次对话中生效”一类文案，不要求用户理解更新、修复、快照或摘要。结果无法确认时继续沿用现有“刷新插件列表”反馈，不能自动重试安装请求。

## 3. 权限规则

Server 以插件 ID 查找现有的用户级安装记录。权限判断必须在 Server 端完成，不能只信任 Desktop 传入的状态。

- 新插件未请求权限：直接安装。
- 新插件请求权限：显示一次完整权限确认。
- 已安装插件本次请求的权限，是之前已批准权限的子集或相同集合：直接重新安装，不重复确认。
- 已安装插件新增了任意权限：显示一次完整的当前权限确认，不设计逐项差异界面。
- managed 插件仍然禁止被用户 ZIP 替换。

Archive preview 增加一个由 Server 计算的 `approvalRequired` 结果。安装时 Server 再次读取当前安装记录并重新判断，防止 preview 与 install 之间状态变化。Desktop 在无需确认时可以不提交权限列表；Server 只在既有批准完整覆盖本次请求时复用批准，并将安装器需要的有效批准收紧为本次实际请求集合。

## 4. 安装记录与失败行为

重新安装同一用户插件时：

- 保留原 `installedAt`；
- 保留用户当前的 `enabled` 状态，不能因为重新导入而把已禁用插件自动启用；
- 更新 `currentVersion`、`cachePath`、内容摘要、当前请求权限、当前有效批准和 `updatedAt`；
- 成功后沿用现有 Runtime 失效机制，新内容从下一次对话开始加载。

任何发生在安装记录切换前的解压、校验、权限或快照错误，都返回失败并保留旧安装记录。安装成功但 Desktop 暂时无法刷新列表时，返回“结果暂无法确认”，由用户刷新列表确认，不再次发送安装请求。

重新导入的 ZIP 不保存为长期来源，也不提供自动回退。旧快照继续按现有保留规则处理，本阶段不增加垃圾回收。

## 5. 修复语义

“修复”不是新命令。用户发现插件安装状态无效时，重新导入可信 ZIP：

- 如果目标快照不存在，安装器重新创建；
- 如果同版本、同摘要快照损坏，现有 cache 逻辑隔离损坏目录并重建；
- 如果 ZIP 本身无效，旧安装记录保持不变；
- 如果原始 ZIP 已丢失，系统只提示用户重新选择可信 ZIP，不尝试信任损坏 cache。

## 6. 最小改动边界

本阶段允许修改：

- Native Installer：重新安装时继承 `enabled`；
- Server Plugin Service：preview/install 复用既有批准并返回是否需要确认；
- Desktop main/renderer：依据 Server 结果决定是否显示现有权限确认，并调整成功文案；
- 对应类型、窄范围测试和插件文档。

本阶段明确不做：

- 自动检查或下载更新；
- Git、npm、Marketplace 来源刷新；
- 独立 Update/Repair API 或命令；
- 版本历史、回滚界面和版本选择；
- ZIP 长期保存；
- 旧快照垃圾回收；
- Agent 对话安装；
- 新的权限差异界面。

## 7. 验证重点

只覆盖本次行为变化：

- 重新安装保留禁用状态和首次安装时间；
- 相同或减少权限时不重复确认；
- 新增权限时仍必须确认完整权限集合；
- 替换失败时旧安装记录保持不变；
- Desktop 继续只展示成功、失败或结果暂无法确认。

现有不可变快照、ZIP 安全解压和完整 Desktop 安装验收不在本阶段重复扩写。
